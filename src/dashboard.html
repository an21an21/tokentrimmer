"view" shows what was rewritten in one of the last 10 rewritten requests (kept in memory only). Token counts are estimates (about 4 characters per token). "Billed input" is the figure the API reported for the request it received. In dry-run mode, requests are measured but forwarded unchanged. "Check" shows the result of decoding each rewritten request back and comparing it with the original; "lossless" means every change was proven reversible, and a failed check sends your original request.
